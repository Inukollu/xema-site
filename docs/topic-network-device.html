network-device

Network devices are the other devices the server can see on the network attached to an interface, such as phones, switches, routers and computers.

By default the list shows only devices the server has already exchanged traffic with. A server that has just started may have seen very few.

Scan network

Scan network checks every address on the network and lists the devices that respond. It takes a few seconds and is safe to run at any time. Devices configured to ignore such checks may still not appear.

Columns

  • Hardware address: the device's MAC address.
  • Vendor: the manufacturer of the network adapter, derived from the hardware address. Blank when the manufacturer is not known.
  • Name: the device's name, when the network provides one.
  • State: how recently the server received traffic from the device.
