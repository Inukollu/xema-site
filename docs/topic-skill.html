skill

A skill marks what an agent can handle, such as a language, a product line or a type of request. Each queue is linked to one skill, and only agents who have that skill receive its calls.

Agents

  • Agents shows how many agents have each skill. A skill with no agents means a queue that uses it has no one to answer its calls.
  • Skills are assigned on the agent's own page, or to several agents at once from the skill.
  • An agent can have any number of skills. Adding a skill does not change their other skills.
  • Skill changes take effect at once. Queues update which agents can take their calls as soon as an agent's skills are saved.

Description

The description is shown only in Xema Manager. Queue pages show the skill by name, so choose a clear name.

Commands

  • xema skill add
  • xema skill fields
  • xema skill remove
  • xema skill set
  • xema skill show
  • xema skills
