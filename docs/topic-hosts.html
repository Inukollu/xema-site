hosts

The hosts are the names and addresses a cluster's services answer at.

Allowed addresses

By default every service answers at any address. Only the cluster's own addresses and those listed restricts this: each server's address, its Agent UI names and loopback are always allowed, and any other host name or address must be listed, one per line, for example a load balancer's name. Each server applies a change within a minute, except Manager's sign-in, which reads the list at startup: run xema restart manager on each server after a change.

Commands

  • xema hosts
  • xema hosts add
  • xema hosts any
  • xema hosts limit
  • xema hosts remove
