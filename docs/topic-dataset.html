dataset

A dataset is a list of numbers for dialers to call. Numbers are added by uploading .csv files as batches, and the dialer works through the batches in order.

Details

  • A dataset has a name and a description.
  • With Duplicate check on, a number repeated in a file or already in the dataset is stored but marked not valid.

File format

The first .csv file sets the dataset's file format: which column holds the phone number, and which field each other column maps to. Every later batch must use the same format. The format cannot be changed, because lookups depend on it.

  • One column must map to Number.
  • A column can be left out.
  • Each field can be mapped to only one column.
  • A date field needs a date format and a time format.

Uploading a batch

Each upload adds a .csv file of numbers to the dataset as a new batch. The file is checked first. When the check passes, the batch is given a name and uploaded.

  • The file must have the .csv extension.
  • It must have the same format as the dataset's first file: at least as many columns, and the same header text in every column the dataset reads by header.
  • The dataset must have a column mapped to the phone number. Nothing can be uploaded until it does.
  • A file with the same name as an earlier batch shows a warning but is not refused, as it may contain the same numbers. Give each file a unique name.

Batches

A batch is one uploaded file and the results of reading it. Each batch shows how many records its file contained and how many were valid, invalid or duplicates.

  • Invalid records had no number, or a number too long to dial, and were not stored.
  • Duplicates repeat a number already in the file or the dataset. They are stored and marked not valid, so dialers skip them.
  • The counts are kept up to date: correcting a row can move it between valid and duplicate, and deleting rows reduces the counts. Invalid records stay counted, since they were never stored.
  • Delete rows deletes every row in the batch and keeps the batch. Only managers and administrators can do this. Dialers that already loaded the batch keep their own copy.

Rows

  • A row is one number in the dataset, with its values under the dataset's column names. Rows can be shown as all rows, valid rows, rows that are not valid, or duplicates.
  • The number or any of its values can be edited. Whether the number is valid or a duplicate is checked again when the row is saved.
  • Dialers that already loaded a row's batch keep their own copy, so edits and deletions do not change that copy.
  • Only managers and administrators can delete a row. The batch counts are updated when a row is deleted, or when an edit changes whether it is valid or a duplicate.
