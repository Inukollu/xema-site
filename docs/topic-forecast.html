forecast

The forecast estimates the calls each queue will receive in every 15-minute interval. From those calls, the expected handle time and each queue's service level, it calculates how many agents are needed. The forecast is always enabled.

How it is calculated

Each interval is forecast from the same weekday and interval in up to eight previous weeks, with recent weeks weighted more heavily. An interval is forecast only after it has data from at least four of those weeks; until then, Live View shows that there is not enough history.

15-minute figures are kept for 13 months, so older data is not used.

Where it is shown

Live View shows forecast calls beside calls received, and required agents for each skill beside available agents. A queue needs a service level target (an answer time and a percentage) before required agents can be shown for it.
