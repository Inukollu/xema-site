agentphone

The transfer action is a button the agent can use during a call from a queue to transfer the caller to another phone.

Fixed phone or agent prompt

  • With Prompt agent for number off, the caller is always transferred to the phone in Phone ID, entered as its device name.
  • With it on, the agent enters the number when they use the button. If no number is entered, the transfer is refused and the caller stays with the agent.

Notes

  • Name is the button label the agent sees. Keep it short.
  • If the number cannot be reached, the transfer is refused and the caller is not disconnected.

Commands

  • xema agentphone add
  • xema agentphone fields
  • xema agentphone remove
  • xema agentphone set
  • xema agentphone show
  • xema agentphones
