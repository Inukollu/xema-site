dns

DNS settings decide how a server resolves names to addresses. Static entries are checked first, search domains complete names without dots, and DNS servers are queried last. These settings affect only this server, not other devices on the network.

DNS changes take effect when saved. They do not wait for Apply changes like the rest of the network settings.

Servers

  • The DNS servers this server queries, entered by address, not by name.
  • Leave it empty on most servers. A network that assigns addresses usually assigns DNS servers as well, and those are already in use.
  • These are the server's default DNS servers. An interface that received its own DNS servers with its address uses those for its own traffic.
  • List the nearest server first. Servers are tried in order, and a slow server delays every lookup that the earlier servers cannot answer.

Search domains

  • Domains added to a name without dots. With example.com set, a lookup for crm becomes crm.example.com.
  • Domains are tried in order for every name that is not found, so keep the list short.

Static entries

  • Names this server resolves itself, without querying DNS. Use them for a host your DNS does not know, or to point a name to a different address on this server only.
  • A static entry takes precedence over DNS. Check here first when a name resolves to an unexpected address.
  • One address can have several names; enter them on one line, separated by spaces.
  • Entries added in Xema are listed apart from entries that were already on the server. Those are shown for reference but cannot be changed in Xema.

Commands

  • xema dns
  • xema dns domains
  • xema dns servers
