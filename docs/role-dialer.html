Dialer

Dialer places outbound calls for the cluster's dialers and hands answered ones to agents.

It is not given automatically. Put it on the servers that should call out.

Putting it on a server

sudo xema node role add dialer
sudo xema node apply

node role add records that this server should run it, and node apply starts it. If xema component list shows it is not installed here, install it between the two:

sudo xema component install dialer

A server can also be given it as it joins: sudo xema join ... --roles dialer,....

Taking it off

sudo xema node role remove dialer
sudo xema node apply

Checking it

xema node roles          # what this server should run, beside what it runs
xema status              # every service on this server, running or not
xema logs dialer

Restarting it

sudo xema restart dialer                       # on this server
sudo xema node restart dialer --node <server>  # on another one

Restarting drops the calls it is carrying.

Running a dialer

sudo xema dialer start <dialer>
sudo xema dialer stop <dialer>
sudo xema dialer refresh <dialer>     # read its datasets again, so rows added since are dialled
