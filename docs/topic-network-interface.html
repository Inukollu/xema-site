network-interface

A network interface is a server's connection to a network. Each interface is shown with its current addresses, and VLANs are listed under the interface they use.

Editing an interface or adding a VLAN does not take effect at once. Changes are staged and take effect only when they are applied with Apply changes.

Automatic rollback

When changes are applied, the server switches to the new settings and starts a timer. If the change is not confirmed before the timer ends, the server restores the previous settings. This prevents a wrong address from making the server unreachable.

If the change moves the server's address, the browser loses its connection. Open the new address and confirm from there.

Status

  • Up: the link is working.
  • No cable: no cable is connected, or the other end is switched off.
  • Down: the interface is disabled in the settings.
  • Not present: the settings include this interface but the server cannot find it. For an interface added in Xema, this means it has not been applied yet.

Pending changes

Until changes are applied, the interface keeps working as its status shows.

  • Pending addition: added in Xema; not yet on the server.
  • Pending change: edited since the last apply.
  • Pending removal: still active, but removed on the next apply.

Wait at boot

Whether the server waits for this interface during startup. Leave it enabled for the interface used to reach the server. Disable it for an interface that is not always connected, or startup is delayed every time.

IPv4 addressing

  • Automatic (DHCP): a router on the network assigns the address.
  • Manual: you set the address. Use this for any device that others must reach at a fixed address.
  • No IPv4: the interface carries traffic but has no address of its own. This is normal for an interface used only for VLANs.

Address source

An interface can have several addresses from different sources, so each address shows its source.

  • Static: a fixed address configured on the server, in Xema or elsewhere.
  • DHCP: assigned by a router on the network, with a lease that is renewed.
  • Automatic: an IPv6 address the interface configured itself, from the router or from a lease.

Sources are read from the running system, so addresses configured outside Xema are also shown correctly. An interface with no address shows its state instead: waiting for a lease, no address, or not configured.

Address format

Enter addresses in CIDR notation, for example 192.168.1.10/24. A /24 covers 192.168.1.1 to 192.168.1.254.

Default gateway

The router used for traffic to other networks. Only one interface on the server should have a default gateway; leave it blank on the others.

DNS servers

The servers used to resolve names. If unsure, use the same DNS servers as the rest of your network.

Static routes

Needed only when a network is reached through a router other than the default gateway. Enter the destination network in CIDR notation and the gateway router for it.
