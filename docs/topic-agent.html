agent

Agents are the people who take and place calls. Each agent signs in to Agent UI with their username. The team decides where they appear in reports and in Live View, and their skills decide which queues can route calls to them.

Agent account

  • The username is what the agent signs in with. It cannot be changed after the account is created.
  • The password is set when the account is created. Change password sets a new one at once; the agent uses it the next time they sign in.
  • The handset PIN lets the agent sign in at a desk handset with their agent number and this PIN. Set handset PIN replaces it at once with 4 to 12 digits. It is never shown, even to you, so it can only be replaced. Whoever sets it can sign in as the agent, so only someone above the agent's level can set it.
  • Five wrong passwords lock the account for five minutes. Unlock removes the lock at once.

Routing

  • The team decides where the agent appears in reports and in Live View, and which team capabilities (dialing, barge) apply.
  • Skills decide which queues can send calls to the agent. An agent without skills receives no queue calls.

Live status

  • The dot shows the agent's state: green when idle, violet while busy on a task, amber on a break, red when offline.
  • Below it are the location the agent is signed in from and the phone they are using.
  • The status refreshes every 15 seconds.

Session actions

  • Sign out ends the agent's active session, as if the agent had signed out themselves.
  • Reset session clears the agent's session on the server. Use it when the agent's app crashed or lost its connection and the agent cannot sign in again.

Listen, coach and join

  • On the agents list, an agent on a call shows Listen, Coach and Join, if you hold the permission to coach agents.
  • Listen lets you hear the call without being heard. Coach lets the agent hear you, but not the caller. Join adds you to the call, so both the agent and the caller hear you.
  • Your browser asks for the microphone the first time, before anything rings. The top bar shows what is under way, with End, on every page until you end it.
  • The list shows who is on a call only while it is open. Calls you may not reach are refused, with the reason.
