customapp

A Custom App XApp sends the call to a custom dial plan written for this cluster outside Xema Manager. Registering it gives that dial plan a name in Xema, so a DNI, a flow or a dialer can send calls to it like any other XApp.

Context name

The name of the dial plan context the call is sent to. It must exactly match the context on the phone system. Xema does not create it and cannot check it; ask the person who maintains the dial plan.

Behaviour

  • What happens to the call after it is sent, including whether it returns, depends entirely on that dial plan.
  • A wrong context name is not reported. Calls sent to the XApp simply go no further, so make a test call after registering.
  • Unregistering removes the name from Xema. The dial plan itself is not changed, and any DNI or flow step that still points to the XApp stops working, so check those first.
  • The name cannot be changed later; flows and DNIs refer to this XApp by name.

Commands

  • xema customapp add
  • xema customapp fields
  • xema customapp remove
  • xema customapp set
  • xema customapp show
  • xema customapps
