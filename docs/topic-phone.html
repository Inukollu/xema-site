phone

A phone is a SIP extension: the number a phone device registers with and the line an agent takes calls on. Every phone belongs to a phone group, which sets what the phone can do.

Phone account

  • Number is the SIP extension the phone device registers with. It also identifies the phone throughout Xema.
  • Password is what the device authenticates with; agents never see it. A new phone is given a six-digit password, which you can change to whatever the device requires.
  • Group sets what the phone can do: the listen and coach codes, outbound dialling, the trunk and caller ID it uses, and recording.

Live status

  • The dot shows the phone's state: green when idle, amber while ringing, violet on a call, red when offline.
  • The phone's details show the device (SIP client and address) registered on the number and the agent currently signed in on it.
  • The status refreshes every 15 seconds. The ring shows when the next refresh is due.

Commands

  • xema phone add
  • xema phone assign
  • xema phone password
  • xema phone remove
  • xema phone show
  • xema phone unassign
  • xema phones
