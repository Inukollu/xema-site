cors

A cluster lets pages from other sites call it only when it names those sites.

Allowed sites

A browser allows a page from one site to call another site only if that site permits it. The cluster's own pages are always permitted. List an integrating application's site, with its scheme and any port, such as https://crm.example.com, and its pages can call Manager and Metrics within half a minute, with no restart. Any site permits pages from every site; leave it disabled unless that is intended.

Commands

  • xema cors
  • xema cors add
  • xema cors any
  • xema cors limit
  • xema cors remove
