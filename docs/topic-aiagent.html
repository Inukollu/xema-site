aiagent

An AI Conversation Agent greets the caller and holds an open conversation, using its tools to answer questions. The conversation ends when the caller hangs up, or, if exit keys are set, when the caller presses one. The call then continues in your flow.

Tools

  • JSON API tools use your Json Api XApps. Each {placeholder} in the URL, headers or body becomes a tool parameter that the model fills in. {CLI}, {ANI} and {CALL_UUID} are filled in from the call automatically.
  • The Json Api XApp's description tells the model when to use the tool. Write it as an instruction, for example "Gets the prepaid balance for a phone number".
  • MCP servers are connected when the call starts, over streamable HTTP. All of their tools are available to the agent.

Settings

  • Guardrails define the persona and its limits. State what the agent must not discuss.
  • Exit keys are DTMF characters, for example 0*#. Pressing any of them ends the agent at once, and the call continues in your flow.
  • The transcript variable holds up to 8,000 characters. The full transcript is stored in the CDR database under the call's ID.
  • The timeout disconnects the call. Use it as a safety limit, not to control the flow.

Behaviour

  • The agent starts in the channel's language and switches to the caller's language.
  • Callers can always interrupt the agent while it is speaking.
  • Agent settings are cached, so changes can take up to 5 minutes to reach new calls.

Commands

  • xema aiagent add
  • xema aiagent fields
  • xema aiagent remove
  • xema aiagent set
  • xema aiagent show
  • xema aiagents
