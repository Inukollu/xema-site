language

A language is one that calls can be handled in. Audio prompts are recorded once per language, and a flow changes a call's language with a Set Language step.

Code

  • The code is used by the phone system to find a language's sound files, and every recording in that language is stored under it.
  • Codes come from ISO 639-1 (two letters) or 639-2 (three letters). Hindi is hi in 639-1 and hin in 639-2.
  • Two-letter codes such as en or hi are the usual choice and match the phone system's sound folder names.
  • A code that is on neither list is accepted as entered. The phone system must have a sound folder with that name.
  • The code cannot be changed once prompts have been recorded in the language.

Name

  • The name is shown on the audio and flow pages, for example English or Hindi.
  • Choosing a code from an ISO list fills in the name. The name can be changed at any time.

Prompts and deleting

  • Prompts shows how many recordings exist in the language.
  • A language with recordings cannot be deleted. Delete those recordings on the audio pages first.
  • After a language is deleted, a flow step that switches to it leaves the call in its current language.

Commands

  • xema language add
  • xema language fields
  • xema language remove
  • xema language set
  • xema language show
  • xema languages
