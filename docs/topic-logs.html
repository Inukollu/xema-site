logs

Each service on a Xema server writes its own log. The log can be read live, for a set period, or filtered by level and text. How much a service logs is set by its log level.

Time range

  • Follow shows new lines as they are written. If the connection drops, it resumes where it stopped.
  • Latest shows the last few hundred lines without updating.
  • 15m / 1h / 6h / 24h show that period. The exact range is shown beside them.
  • Custom takes a start and end time. Leave To empty to show everything up to now.

Filtering

  • The level filter hides entries below the selected severity.
  • Search shows only lines whose message contains the text you enter. Both filters work on the lines already loaded.
  • The count at the bottom shows how many of the loaded entries are shown.

Reading the log

  • Errors are shown in red, warnings in amber and debug lines dimmed.
  • The level is taken from the journal's priority, not from the message text.
  • Time switches between oldest first and newest first.
  • A followed log opens at the newest line and stays there as lines arrive. If you scroll up, it stops moving; scroll to the end to follow again.
  • A followed log keeps the most recent 1,000 lines.

Commands

  • xema logs
  • xema logs backup
