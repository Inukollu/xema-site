xapp

XApps are the applications a call can be sent to. A call arriving on a trunk goes to the XApp set on its DNI, and a flow sends calls to other XApps with an Exec XApp step.

Types

  • Flow: the call menu. Plays audio, collects input, branches and queues the caller.
  • Dataset Lookup: finds the caller in a dataset and copies values from their row into variables the flow can read.
  • Call Counter: counts how often a number has called since the last reset, and returns the count.
  • Json Api: calls a web service while the caller waits and reads values from the response.
  • Dial Out: sends the call out over a trunk.
  • Custom App: sends the call to a custom dial plan written for this cluster.
  • AI Input Agent: asks the caller a question and stores the answer in variables.
  • AI Conversation Agent: holds a conversation with the caller.

Type and name

  • The type is chosen when the XApp is created and cannot be changed later. To change it, create a new XApp.
  • The name cannot be changed later. Flows, DNIs and dialers refer to an XApp by name, so choose a name that is easy to recognise in a list.

Commands

  • xema xapp show
  • xema xapps
