callcounter

The call counter XApp counts how often a number has called. Each time a call reaches it, the caller's count goes up by one, and the new count is returned in a variable for the flow to use. A first call since the last reset returns 1.

The count is always for the caller's own number. Every call is counted, including repeat calls within the same minute.

Settings

  • No of digits to match compares only that many digits of the caller's number from the right, so the same caller is recognised with or without a prefix.
  • Variable name is the variable the count is returned in.
  • Cache dataset is where the counts are stored. Use a dedicated dataset for each counter; it is cleared every time the counter resets.
  • The name cannot be changed later; flows refer to the XApp by name.

Reset

When all counts go back to zero: Never, every day, on the weekdays you choose, or on a day of the month (the 1st to the 28th, or the last day), each at a time. The time is in the site's time zone, shown beside it, and stays the same clock time when the clocks change.

A reset set some other way, which these choices cannot show, appears as Custom with its description. It is kept as it is until a new one is chosen.

Using it in a flow

Add an Exec XApp step for the counter, then branch on the variable with an If step. For example, when CALL_COUNT is greater than 3, send the caller directly to an agent instead of through the menu.

Commands

  • xema callcounter add
  • xema callcounter fields
  • xema callcounter remove
  • xema callcounter set
  • xema callcounter show
  • xema callcounters
