binding

A network binding sets what one of a server's addresses is used for. A server usually has several addresses, each with its own purpose.

Purposes

  • Agent apps: Agent UI, the WebRTC phone and the CRM pages agents open. Enter the host name agents' browsers use; the server needs a valid certificate for that name.
  • Desk phones: the address desk phones register to.
  • Trunks: an address trunks send and receive SIP on. Each trunk selects one on its own form.
  • Trunk media: an address for a trunk's media, when it should differ from its SIP address.

An address can have more than one binding, and two trunks can use two addresses of the same server.

Server

Bindings apply to one server. An address is accepted only if the server has it now or its staged network configuration assigns it.

Deleting a binding

A binding used by a trunk cannot be deleted. Assign other bindings to those trunks first.

Commands

  • xema binding add
  • xema binding remove
  • xema bindings
  • xema bindings apply
