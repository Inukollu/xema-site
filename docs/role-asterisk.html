Phone system

The phone system carries the calls on a server: its trunks, its phones and the channels of every call. Its role is named asterisk.

A trunk decides which servers carry calls. Assigning a trunk to a server makes it one, and gives it the services such a server runs: Queue, Bridge, Park, Recorder, Tone, AsterMQ, Fastlane, FastAGI and Sipper.

Where it is recorded

sudo xema node role add asterisk

This records which server holds it. It is recorded only: xema node apply never starts, stops or moves it, because moving it moves data with it. xema join and xema init set it up where it belongs.

xema node roles          # this server's roles, beside what is running
xema status              # every service on this server, running or not

Trunks

xema trunks                                   # each trunk and the server it is on
sudo xema trunk assign <trunk> --node <server>
sudo xema trunk unassign <trunk>

Assign a trunk to the server its circuit is plugged into. Unassigning a server's last trunk leaves the services it was given; xema node role remove takes them off.

Restarting it

sudo xema restart asterisk

Every call on the server drops.
