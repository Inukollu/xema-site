Host

The host agent is what makes a machine a node. It applies the server's network plan and clock, starts and stops the other services as the cluster says, and reports back.

It is on every server, and is not a role you add or remove. xema init and xema join put it there first, and nothing stops it.

Checking it

xema status
xema logs host
sudo xema node files      # places the service files this build carries, and starts the host agent
xema node check           # checks this server's token and web server files
