role

A role is a set of permissions that can be assigned to users.

Standard roles are provided with Xema, such as Admin, Manager and Agent. They cannot be edited or deleted, and Xema only lists the permissions they grant. Custom roles are created to grant a different set of permissions, and are assigned to users in the same way as standard roles.

Permissions

A role has a name and the permissions it grants. Each row is an area of Xema, and each column is an action in that area: View to see it, Edit to change it, Run to start and stop it, and Live and History to view current and past figures.

What you can grant

A role can grant only permissions you hold yourself. If you select a permission you do not hold, saving fails and the message names the permission. To edit or delete a role, you need every permission it grants, both before and after the change.

Deleting a role

Users who hold the role lose its permissions immediately.

Commands

  • xema role add
  • xema role fields
  • xema role permissions
  • xema role remove
  • xema role set
  • xema role show
  • xema roles
