lookup

A Dataset Lookup XApp looks up a number in a dataset and copies values from the matching row into variables. The call then continues from where it came in, with those variables set for the rest of the call.

Lookup

  • Variable name is the value to search for. CLI or ANI means the caller's number; any other name is read from a variable set earlier in the call.
  • No of digits to match compares only that many digits from the right, so numbers stored without a country or area code still match. The usual value is 10.
  • Dataset is the dataset to search, with one row per number. The first matching row is used.

Variables

Each of the five rows sets one variable: its name and the dataset column its value comes from, for example CUST_NAME from text1 and CUST_TYPE from text2. Variable 1 is always enabled; enable the others as needed.

Using it in a flow

  • Add an Exec XApp step for the lookup, then read the variables with If steps.
  • When no row matches, the variables are empty. Add a route for that case, or those calls are not routed.
  • The name cannot be changed later; flows refer to this XApp by name.
  • Dataset contents are managed under Datasets.

Commands

  • xema lookup add
  • xema lookup fields
  • xema lookup remove
  • xema lookup set
  • xema lookup show
  • xema lookups
