cluster-settings

Settings control how a cluster behaves. Each section is saved separately.

Changes take effect immediately. Services that cache these settings reload them, so an agent who signs in a moment later gets the new setting without any restart.

The manual dialer

A manual dialer places the calls agents make themselves: their own calls, call backs and conference parties. Xema uses the one named on the agent's queue, then their team, then their process, and last the one named in these settings. With none named anywhere, those calls are refused. Only a dialer of the Manual type can be chosen.

Scheduled calls

Scheduled calls are calls an agent books for later. These settings are for calls booked outside any process. A process's own settings decide for its calls.

  • Place scheduled calls: whether booked calls are placed.
  • Agent: who takes a call when it is due. Choose only the agent who booked it, that agent if they are free and otherwise any free agent, or any free agent.
  • Dialer: the dialer that places the calls. It must be in no process, and not an agentless one. Its kind sets the pacing.

While scheduled calls are on, both the agent and the dialer are required. When they are off, the choices are kept for next time.

Agent alert

The prompt an agent hears as a call connects, where neither the queue nor its process names one. With none, agents hear a beep.
