standard-report

Standard reports are provided with Xema and their content cannot be changed. What can be set is the report's owner and who can use it.

Owner

  • The owner can always run the report and can share it from Data Portal.

Access

  • View lets them run the report in Data Portal. Results are saved, so they may see a result calculated earlier.
  • Refresh also lets them recalculate a saved result with the latest data.
  • Admin and Manager always have access. Sharing is for everyone else.
  • Team Lead and Quality Analyst are always listed, as is any role with access. Show more roles lists the rest. Roles created on this system are marked Custom. Clear View to remove access.
  • Sharing with a user gives access to that user only, whatever their role.
