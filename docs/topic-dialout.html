dialout

A Dial Out XApp sends the call out over a trunk and connects the caller to whoever answers. The number dialled is the number the call was routed to, so it forwards a call off the system; it does not choose a new destination.

Trunk

The trunk the outgoing call uses. The route, prefix and caller ID shown to the called party are set on the trunk, not on the XApp.

Where it is used

  • As the target of a DNI, to forward calls to that number straight back out.
  • In a flow, with an Exec XApp step, when a menu option should send the call off the system.

Behaviour

  • If nobody answers, or the trunk cannot place the call, the call returns to the step after the one that sent it. Add a step there, or the caller reaches the end of the block and is hung up.
  • The outgoing call counts against the trunk's limits like any other call.
  • The name cannot be changed later; flows and DNIs refer to this XApp by name.

Commands

  • xema dialout add
  • xema dialout fields
  • xema dialout remove
  • xema dialout set
  • xema dialout show
  • xema dialouts
