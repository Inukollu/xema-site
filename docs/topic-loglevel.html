loglevel

A log level sets how much a Xema service writes to its log. It can be changed while the service runs, and it applies only to Xema's own services.

Setting a level

  • tune sets how much a service logs. It is available for Xema's own services; Asterisk, MariaDB and other services are configured on the server.
  • Default sets the level for the whole service: entries below it are not written. Raise it when you need more detail, and lower it again afterwards.
  • Each other line sets the level for one part of the service, identified by a label. Support will tell you which label and level to set; delete the line when the issue is resolved.
  • Changes take effect within a few seconds, without restarting the service, and remain after a restart or reboot.
  • Use Trace and Debug with care on a busy service. They write a large volume of detail, which can include customer information visible to anyone who can read the logs. Lower the level when you are done.

Commands

  • xema loglevel set
  • xema loglevel show
  • xema loglevels
