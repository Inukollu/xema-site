backup

A backup is a copy of the database, taken on the server that has the database role. If no server has the database role, backups are not available.

Back up now

  • Back up now starts a backup at once, in addition to any scheduled backups. The backup is listed when it finishes.
  • If the last backup failed, Xema shows the reason.

Schedule

  • No automatic backups are taken until a schedule is saved. Xema shows a warning until then.
  • Time is the time of day the backup runs, in 24-hour format (02:00 is 2 a.m.), in the time zone shown beside it. Choose a quiet hour.
  • Keep is the number of backups to keep, from 1 to 365. Older backups beyond that number are deleted only after a successful backup, never after a failed one.

Backups

  • Backups are listed newest first, with the time in your computer's time zone.
  • Incomplete marks a backup that did not finish. It can be downloaded, but it is not a complete copy of the database.
  • Generation shows which version of Xema created it, V1 or V2.
  • Download saves the backup to your computer as a compressed archive. Keep a copy away from the server, so that it is not lost with the server.

Commands

  • xema backup
  • xema backup list
  • xema backup prune
