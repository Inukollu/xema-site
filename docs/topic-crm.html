crm

A CRM link is a URL that opens the caller's record in your CRM when a call from a queue is offered to an agent, so the record is ready when they answer. Call details, such as the CLI, are inserted into the URL.

Settings

  • Reuse tab opens the CRM in the same browser tab each time instead of a new tab for each call.
  • Show link shows the URL as a link in Agent UI instead of opening it automatically.

URL template

Each name in double braces is replaced with the call's value, URL-encoded, before the link is sent to the agent. A percent-encoded placeholder such as %7B%7B%20CLI%20%7D%7D works too.

https://crm.example.com/sr/?PHONENUMBER={{ CLI }}&CUCID={{ CALL_UUID }}&AGENTID={{ AGENT_USERNAME }}

Named placeholders

These are always available:

  • {{ CLI }}: the caller's number.
  • {{ CALL_UUID }}: the call's ID, as stored in its call record (CDR).
  • {{ AGENT_USERNAME }}: the agent's username.
  • {{ AGENTID }}: also the agent's username, kept for compatibility with V1.
  • {{ QUEUE }}: the queue's name.
  • {{ PHONEID }}: the agent's phone.
  • {{ UNIQUEID }}: the caller's channel ID.

Call variables

Any channel variable set on the call before it reaches the agent can be used the same way, for example {{ CIRCLEID }}, or a variable set by the call flow such as {{ ACCOUNT_NO }}.

Rules

  • Names are not case-sensitive: {{ cli }} and {{ CLI }} are the same.
  • A name with no value on the call is replaced with nothing.
  • Single braces are plain text. Links saved in the old {CLI} form are converted during the upgrade.

Commands

  • xema crm add
  • xema crm fields
  • xema crm remove
  • xema crm set
  • xema crm show
  • xema crms
