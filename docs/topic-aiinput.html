aiinput

An AI Input Agent plays the announcement, listens to the caller and sets the output variables. It then returns the call to your flow, which reads the variables and routes the call.

Output variables

The description is the model's instruction. Name the exact values your flow checks for, and always define a fallback value, for example: Set exactly '1' for sales, '2' for support, '0' if the caller did not make a clear choice.

Using it in a flow

Add an Exec XApp step for the agent, then branch on the variable with If steps, for example SELECTED_SERVICE = '1' goes to sales. Always give the fallback value a route as well.

Behaviour

  • The agent starts in the channel's language and switches to the caller's language.
  • The transcript variable holds up to 8,000 characters. The full transcript is stored in the CDR database under the call's ID.
  • The timeout disconnects the call. Use it as a safety limit, not to control the flow.
  • Agent settings are cached, so changes can take up to 5 minutes to reach new calls.
  • Turn on Allow early answering to let callers speak over the announcement. When it is off, the caller can speak only between sentences.

Commands

  • xema aiinput add
  • xema aiinput fields
  • xema aiinput remove
  • xema aiinput set
  • xema aiinput show
  • xema aiinputs
