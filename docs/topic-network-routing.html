network-routing

A route tells the server where to send traffic for a particular network. Most servers need only a default route, which is the gateway set on an interface.

Adding a route

Add a route when a network is reachable through something other than the default gateway, such as another router on the same LAN, or a range a carrier asks you to route a specific way.

  • Destination: the network in CIDR notation, for example 10.0.0.0/8.
  • Through: the address of the router for that network. It must be on a network the server can already reach.
  • Priority: needed only when two routes cover the same destination. The lower number is used.

Default route

The default route is the gateway, which is set on its interface, not as a route. A carrier's gateway is set on its SIP realm and applies only to that carrier.

Active routes

The active routes are every route the server is using, including routes it adds automatically and routes from other software on the server. They are read-only, but they explain where traffic is sent.
