music

Hold music is played to callers waiting in a queue. It comes in music classes. A music class is a set of files played in rotation while callers wait. Upload several files for variety.

Each queue selects one class as its music on hold. Changing the files of a class changes the music for every queue that uses the class.

Commands

  • xema music add
  • xema music fields
  • xema music list
  • xema music remove
  • xema music set
  • xema music show
  • xema music track-add
  • xema music track-remove
