callerflow

A caller action is a key a caller can press while waiting in a queue. Pressing it removes the caller from the queue and moves them to another flow, for example to leave a callback number or hear other options.

Fields

  • Key: the key the caller presses.
  • Flow: the flow the caller moves to. The caller starts at the flow's first block, or at the block you select when Start at the flow's first block is off.
  • Enable: makes the key available to callers. A disabled action is kept but has no effect. The dot shows whether an action is enabled.

Behaviour

  • Keys work only on a queue with Enable caller actions turned on in its waiting settings.
  • Announce the keys to callers in a promotion. Callers do not press keys they have not been told about.

Commands

  • xema callerflow add
  • xema callerflow fields
  • xema callerflow remove
  • xema callerflow set
  • xema callerflow show
  • xema callerflows
