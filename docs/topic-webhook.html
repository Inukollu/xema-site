webhook

A webhook is a request Xema sends to another system's URL. An integration calls it when an event it subscribes to happens.

Webhook settings

  • When the webhook is called, the URL is requested with the selected method, and the Headers and Body are sent with it. A GET request has no body.
  • Write one header per line, as Name: value.
  • The URL, header values and body are templates. They can use placeholders such as {{ agent.username }}, which are filled in from the event each time the webhook is called. A name the event does not have is left empty.

Locked webhooks

Some webhooks cannot be edited. The Locked count shows how many there are. A locked webhook's page shows its settings read-only, and it can still be deleted. Turning Allow editing off locks a webhook, and it cannot be turned back on here.

Commands

  • xema webhook add
  • xema webhook fields
  • xema webhook remove
  • xema webhook set
  • xema webhook show
  • xema webhooks
