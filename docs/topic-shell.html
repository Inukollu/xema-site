shell

The shell is a terminal on a server of the cluster, equivalent to an ssh session. Line editing, colour and full-screen programs such as top and vim work.

On a cluster with several servers, the server is selected first, and the selection is locked while a shell is open; end the session to switch. A shell can be opened only on this cluster's own servers.

User

The shell runs as root and has full access to the server, including the services Xema Manager manages. The terminal resizes with the window.

Logging

  • All terminal output is written to a transcript on the server, under /var/log/xema/shell, named by user and time. Only root can read transcripts.
  • The server's journal records who opened a shell, from which server, and when it ended.
  • Transcripts are kept until you delete them.

Ending a session

End session closes the shell and its transcript. Leaving the shell, closing the tab or typing exit also ends the session.
