flags

Flags switch optional features of a cluster on or off: the panels Agent UI offers, and whether an agent must sign in with a phone at their own address, and how time on a ban or a break counts. Each flag is off until it is turned on, except An accepted break prompt skips the break limits, which is on until it is turned off.

The agent's screen

Optional panels in Agent UI. Each panel is disabled until it is enabled.

  • CRM dashboard shows the customer view next to the call.
  • Call history lets agents view their own past calls.
  • Missed calls shows calls that rang for the agent and were not answered.
  • My day shows the agent's figures for the shift so far, such as calls handled and break time. When it is disabled, these figures are not calculated.
  • Demonstration content shows content marked as demonstration material, across the cluster.

Signing in to a phone

When an agent signs in, Xema suggests a phone that registered from the same address as the agent's browser. Phone must be on the agent's address makes this a requirement: a phone registered from another address is refused, and the agent is shown the address it is on.

Two exceptions apply. A phone that has never registered is still allowed, because a browser softphone receives its credentials before it registers. An agent can also enter a phone number manually; it is refused only if that phone is registered from another address.

The rule assumes that an agent's browser and phone reach the cluster by the same route. Where they do not (a VPN on the computer, a proxy in front of the web application, or IPv4 for one and IPv6 for the other), every phone at that desk is refused and the agent cannot work. For this reason it is disabled by default. Check how agents connect to the cluster, and test with one agent first.

The rule is useful for hardware phones at fixed desks. Browser softphones always match, so it has no effect on them.

Softphone audio

Softphone audio over TCP (443) sends a browser softphone's call audio through the cluster's TURN relay on port 443, for networks that block UDP. Off for the cluster turns it off for everyone. An agent's own off takes out only that agent.

Agent pauses

How time on a ban or a break counts for agents. A process can set its own value for each, and then its value counts for the agents in that process instead of the cluster's.

  • Ban time counts as break time. When it is off, a ban is counted as its own time.
  • An accepted break prompt skips the break limits. A break an agent takes by accepting a prompt does not count against the team's break limits. It is on by default.
  • Ban time while signed out counts as login time. Time on a ban after the agent signs out is added to their login time.
