break

Breaks are what agents can select when they step away, such as lunch, training or a meeting. Agents see the name and type when they go on a break, and reports group break time by them.

Break settings

  • Type is a fixed list. Four of the types are set by Xema itself, for example when an agent loses their phone or misses a call. For a new kind of break, create a break with the closest type and a descriptive name.
  • Disable a break to stop it being used without losing its history. The dot shows whether a break is enabled.
  • Always allowed marks a break agents can take even while a team lead has suspended breaks. Use it for breaks agents are entitled or required to take, such as rest periods.
  • If unsure, leave it disabled. A break marked always allowed cannot be suspended by a team lead; a break not marked is refused during a busy hour, which the team lead can undo.

Commands

  • xema break add
  • xema break fields
  • xema break remove
  • xema break set
  • xema break show
  • xema breaks
