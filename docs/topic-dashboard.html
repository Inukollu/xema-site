dashboard

The dashboard is a read-only overview of the platform's current activity. It refreshes every 15 seconds; the ring shows when the next refresh is due.

Contents

  • Gauges: disk, memory and CPU use on the server running Manager. CPU is green up to 70%, amber up to 90% and red above.
  • Agents: agents signed in to Agent UI, out of all configured agents.
  • Calls: the number of calls in the system. Until the Metrics service reports its channel count, this shows queued callers only.
  • Cluster activity: talking and waiting over the last few minutes, on a shared scale.
  • Busiest queues today: calls offered, answered and abandoned since midnight. Queues with no calls are not shown.
  • Service status: every service on the server, with platform services on the left and Xema's services on the right. Green is running, red is not. Each one also has its systemd state, uptime and restart count.

Sources

  • The live figures come from the Metrics service, which is deployed separately. If it is unavailable, a banner says so; the rest of Xema Manager continues to work.
  • The service status is the same as xema status on the server. A service that is not shown is not installed on the server.
